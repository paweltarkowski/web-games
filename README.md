# Neon Arcade Collection

This repository contains two small browser-based arcade games built as a playful demo of a vibe-coding experiment.

> This is just an example of vibe coding by Gemini.

## Included games

### 1. Pacman Retro
- Location: [Play Pacman Retro](https://paweltarkowski.github.io/web-games/pacman-retro/)
- Genre: Maze chase game
- Features: neon HUD, retro sound effects, mobile controls, power pellets, ghost AI

### 2. Neon Pong
- Location: [Play Neon Pong](https://paweltarkowski.github.io/web-games/neon-pong)
- Genre: Arcade paddle game
- Features: two-player local play, neon styling, keyboard + touch support, score tracking

### 3. Archelog
- Location: [Play Archelog](https://paweltarkowski.github.io/web-games/archelog)
- Genre: Arcade paddle game
- Features: one-player local play, archelogy style, keyboard + touch support, score tracking
## How to run

Open any game folder and launch `index.html` in a browser.

Examples:
- `pacman-retro`
- `neon-pong`
- `archelog`

No build step or package install is required.

## Notes

These are lightweight front-end demos designed to run directly in the browser with no external asset pipeline. They are intended as a fun creative prototype rather than a production-ready game project.
