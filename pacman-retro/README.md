# Pacman Retro

A browser-based neon Pac-Man clone built as a lightweight retro arcade demo.

> This is just an example of vibe coding by Gemini.

## Gameplay

- Collect all pellets to win
- Eat power pellets to scare ghosts
- Avoid getting caught by enemies
- Track score and lives through the HUD

## Controls

- Keyboard: Arrow keys or WASD
- Mobile: Touch D-pad and swipe gestures

## Run it

Open `index.html` in a browser.

## Stack

- HTML
- CSS
- JavaScript
- Tone.js for sound synthesis
