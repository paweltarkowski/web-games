# Neon Pong

A stylized neon Pong game built as a compact arcade prototype.

> This is just an example of vibe coding by Gemini.

## Gameplay

- Local two-player arcade match
- Score points by getting the ball past the opponent
- Fast reflex gameplay with retro neon aesthetics

## Controls

- Player 1: `W` / `S`
- Player 2: Arrow Up / Arrow Down
- Mobile: touch controls are supported depending on the layout

## Run it

Open `index.html` in a browser.

## Stack

- HTML
- CSS
- JavaScript
